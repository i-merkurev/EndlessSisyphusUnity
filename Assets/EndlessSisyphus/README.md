# Бесконечный Сизиф — Unity-порт

Порт браузерной игры «Бесконечный Сизиф» (Canvas 2D + WebAudio) на **Unity 6** (C#).
Вся игровая логика перенесена почти дословно; рендер — процедурный пиксель-арт.

Целевая версия: **Unity 6000.5.3f1** (Mac Silicon), но собирается и на близких Unity 6.x.

## Как запустить (zero-setup)

1. Unity → открой любой (или новый) проект.
2. `Assets ▸ Import Package ▸ Custom Package…` → выбери `EndlessSisyphus.unitypackage`
   (или просто скопируй папку `Assets/EndlessSisyphus/` в свой проект).
3. Нажми **Play**. Всё создаётся автоматически: `Bootstrap` через
   `[RuntimeInitializeOnLoadMethod]` поднимает камеру, игру и UI — сцену настраивать не нужно.

## Управление

- **Space** — толкать камень (ритмично). Мышь/тап дублируют во время игры.
- **Shift** — усилие на крутом склоне (`Shift`+`Space`).
- **Ctrl** — осторожный режим, только в дождь (вне дождя — ошибка).
- **M** — звук, **Esc** — меню, **R** — заново.

## Структура

```
Assets/EndlessSisyphus/Scripts/
  GameConfig.cs          — баланс (порт CFG)
  Palette.cs             — палитра (порт PAL)
  DifficultySettings.cs  — множители сложности, PlayerPrefs (порт SET)
  Roman.cs               — римские цифры
  PixelCanvas.cs         — софт-растеризатор (Color32[] → Texture2D)
  SisyphusGame.cs        — вся логика: автомат, физика, стамина, препятствия, лёд, сезоны
  WorldRenderer.cs       — рендер мира + спрайт-объекты героев
  AudioEngine.cs         — процедурный звук (дрон+мелодия, SFX)
  GameUI.cs              — экраны/HUD на IMGUI
  Bootstrap.cs           — автозапуск без сцены
```

## Рендер: где подменить арт

Сейчас мир (небо, горы, тропа, лёд, мосты, погода, сезоны) рисуется процедурно в
`Texture2D` и выводится на фоновый `SpriteRenderer`. **Сизиф и валун — уже реальные
объекты `SpriteRenderer`** (`WorldRenderer`: `sisSR`, `bouSR`), которые каждый кадр
трекают позицию и поворот героя.

Чтобы перейти на свой арт:
1. Назначь свои спрайты в `sisSR.sprite` / `bouSR.sprite` (или подставь префабы).
2. В `WorldRenderer` выставь `DrawHeroesInBackdrop = false` — процедурная отрисовка
   героев отключится, останутся твои спрайты.
3. При необходимости подправь пивот/знак поворота (`UpdateHeroTransforms`) —
   координаты мира y-вверх, canvas y-вниз, поэтому угол может потребовать смены знака.

Аналогично можно постепенно выносить в отдельные спрайты фон, горы и т.д.

## Твики

- Баланс — `GameConfig` (static-поля; легко превратить в `ScriptableObject`).
- Цвета — `Palette`. Сложность из UI — `DifficultySettings` (сохраняется в PlayerPrefs).
- Ввод **дуальный**: `SisyphusGame.HandleInput` через `#if` поддерживает и legacy Input
  Manager, и новый Input System — работает при любом значении «Active Input Handling»
  в Player Settings, ничего менять не нужно.

## Статус проверки

Код **скомпилирован против управляемых сборок Unity 6000.5.3f1** (`dotnet build`,
0 ошибок/0 предупреждений) — сборка гарантирована. Игровой прогон и пиксель-точность
картинки/громкость звука доводятся уже в редакторе (у автора порта не было запущенного
Unity для рантайм-проверки). Спрайты героев — процедурные плейсхолдеры под замену на арт.
