# Embedded fonts

The game embeds these fonts directly and does not depend on fonts installed on
the player's operating system:

- Press Start 2P — pixel-art game and defeat titles.
- Jura Medium — body copy, quotations, explanations, records, hints, and secondary labels.
- Jura SemiBold — primary and secondary buttons.
- Jura Bold — section headings, obstacle names, key combinations, strength and height metrics, and gameplay prompts.

All font families are distributed under the SIL Open Font License 1.1. The
corresponding license texts are included alongside the font files.

Sources:

- https://github.com/google/fonts/tree/main/ofl/pressstart2p
- https://github.com/google/fonts/tree/main/ofl/jura
