# Embedded fonts

The game embeds these fonts directly and does not depend on fonts installed on
the player's operating system:

- Cormorant SC Bold — display titles and height values.
- Jura Medium — body copy, instructions, hints, and HUD labels.
- Jura SemiBold — section headings, buttons, and prominent UI labels.
- Playfair Display Medium — literary quotations.

All font families are distributed under the SIL Open Font License 1.1. The
corresponding license texts are included alongside the font files.

Sources:

- https://github.com/google/fonts/tree/main/ofl/cormorantsc
- https://github.com/google/fonts/tree/main/ofl/jura
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay
